# Локомотив × SWM — фан-зона

Исходники промо-лендинга с интерактивами для фан-зоны «Локомотива» и SWM.

## Состав

- `landing-react/` — основная React/Vite-версия лендинга.
- `landing/` — исходная статическая версия и общие графические ассеты.
- `design/` — исходники дизайна карточек.
- `docs/` — рабочая документация по реализации.

## Запуск React-версии

```bash
cd landing-react
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
```

React-приложение использует ассеты из `landing/assets`, поэтому обе директории должны оставаться рядом в корне проекта.
